# Architectural Decisions

- ADR-0001 Package: com.skbsakib.audiosuperpower
- ADR-0002 Kotlin + Compose + Material 3
- ADR-0003 Native via Oboe (LowLatency + Exclusive, best-effort)
- ADR-0004 768 kHz is DSP-only, never hardware (Android CDD caps at 192 kHz)
- ADR-0005 3D-10D is a product naming scheme, not a scientific claim
- ADR-0006 Termux ARM: android.aapt2FromMavenOverride=$PREFIX/bin/aapt2
- ADR-0007 Rootless: no root, no Magisk, no HAL patch, no DRM bypass
- ADR-0008 .skb/ is machine-readable project memory
